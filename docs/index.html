Документация

Установка

1. Скачайте свежий APK из релизов.
2. Разрешите установку из неизвестных источников, когда попросит система.
3. Откройте приложение и выберите источники в каталоге.

Источники

Каталог источников: ReadManga, MintManga, SelfManga, Remanga, Manhwa-сканлейты и другие. Список обновляется вместе с приложением — просто ставьте свежие версии.

Похожая манга

На странице тайтла — карусель из трёх похожих произведений, подобранных по жанрам из того же источника. Кнопка «Ещё» открывает полный список.

Как поделиться мангой

Меню тайтла → «Поделиться»: «Ссылка на мангу в приложении» откроется у получателя сразу в Hanten (если приложение стоит), «Ссылка на источник» — страница тайтла на сайте.

Частые вопросы

Почему некоторых тайтлов нет в каталоге?
Закрытые премиум-тайтлы (только по подписке на сайте) скрываются автоматически — прочитать их в приложении всё равно нельзя.

Ссылка из приложения ведёт не туда?
Убедитесь, что у получателя стоит свежая версия Hanten. Старые ссылки вида hanten.pages.dev больше не используются.

Источник не грузится?
Сайты периодически меняют зеркала. Обновите приложение — зеркала и парсеры обновляются с каждым релизом.
